# Olympic-Games-Data-Analysis-Project
# Project Description -->
This project explores 120 years of Olympic history using the popular Kaggle dataset athlete_events.csv. The dataset contains 271,000+ athlete-event records from Athens 1896 to Rio 2016, covering athlete demographics, event information, and medal outcomes.
The goal of this analysis is to uncover insights about how the Olympics have evolved over time across countries, sports, and athletes.

# Dataset Link --> https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results
# The project performs an end-to-end exploratory data analysis (EDA) of the modern Olympic Games. It includes:
Understanding long-term trends in participation
Evaluating medal performance across nations
Analyzing athlete characteristics
Comparing Summer and Winter Games over different eras
Identifying patterns in sports evolution
This analysis helps answer meaningful questions about global participation, gender representation, dominance of specific countries, and changes in the Olympics landscape.
# ✅ Key Features --
1. Medal Tally Analysis
Year-wise and overall medal counts
Country-wise medal leaderboard
Historcial dominance of nations in Summer and Winter Olympics
Top-performing athletes and sports categories
2. Overall Olympic Analysis
Growth of the Olympics: athletes, nations, and events over time
Trends before and after major historic milestones (e.g., 1992 Games split)
Popular sports based on participation
Evolution of events across decades
3. Country-wise Deep Dive
Medal trend of selected countries over the years
Best performing sports for each nation
Most successful athletes per country
Heatmaps and visual trends using seaborn and plotly
4. Athlete-wise Analysis
Age distribution of Olympians
Height-weight trends across sports
Gender participation evolution
Comparisons of athlete profiles for different sports (e.g., swimmers vs gymnasts)

# 📊 Tech Stack and Libraries -->
Python
NumPy for numerical computation
Pandas for data cleaning and manipulation
Matplotlib & Seaborn for static visualizations
Plotly for interactive charts
Data Preprocessing (handling missing values, filtering, feature engineering)

# 🧹 Data Preprocessing -->
The following preprocessing steps were applied to ensure accurate analysis:
Handling missing height, weight, age, and medal values
Removing duplicate athlete-event entries
Creating helper functions for medal tallies
Extracting year-wise, country-wise, and athlete-wise datasets
Generating cleaned datasets ready for EDA

# 🎯 Insights & Learnings -->
This project highlights:
The rapid global expansion of the Olympics
Shifts in gender representation over time
Countries that consistently dominate
Unique physical characteristics associated with different sports
How the Games evolved pre- and post-1992 restructuring
